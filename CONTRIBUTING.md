# Contributing

Thanks for contributing.

## Development

1. Fork the repository
2. Create a feature branch
3. Add or update tests
4. Run `swift test`
5. Open a pull request

## Commit Style

Use clear messages:

- `feat: add parser for TiB values`
- `fix: handle invalid unit input`
- `test: cover cleanupEfficiency edge case`

## Pull Request Checklist

- Code compiles
- Tests pass locally
- README/docs updated if behavior changed
